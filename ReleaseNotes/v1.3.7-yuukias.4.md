## ClickMate 1.3.7（构建 17）

修复 Mac mini 在 Karabiner CGEventTap fallback 开启时的 Finder 剪切。右键「剪切」和剪切快捷键都使用同一后台流程。后台服务现在从登录会话层发送复制和移动快捷键，保留修饰键，并在最多 350 毫秒内等待 Finder 写入剪贴板。「将……拷贝为路径名称」沿用构建 16 的行为。

Mac mini 实机验收通过 Finder 右键剪切粘贴和 Windows 经 UU 的 Ctrl+X / Ctrl+V。Xcode 共运行 374 项测试，其中 2 项可选截图测试跳过，零失败。

安装包沿用本地 ad-hoc 签名。若系统在升级后提示 Finder 剪切缺少辅助功能，请确认当前安装的 ClickMateHelper 所用的原有权限。

## ClickMate 1.3.7 (build 17)

Fix Finder Cut when Karabiner CGEventTap fallback is active. The Finder context menu and keyboard shortcut use the same background service, which now posts Copy and Move at the login-session tap to preserve modifier flags. It allows up to 350 ms for Finder to populate the pasteboard. The pathname menu keeps its build 16 behavior.

The user confirmed both Finder context-menu cut and paste and Windows Ctrl+X / Ctrl+V over UU on the Mac mini. The Xcode suite reported 374 tests, with two optional screenshot tests skipped and no failures.

The installer uses the existing ad-hoc signing process. macOS may require confirmation of the existing Accessibility permission for ClickMateHelper after updating.
