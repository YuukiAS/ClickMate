## ClickMate 1.3.7（构建 16）

将路径复制设为访达一级快捷操作后，右键单个文件或文件夹会显示「将“文件名”拷贝为路径名称」，多选会显示「将3个项目拷贝为路径名称」等对应数量的标题。「复制」子菜单仍可使用「拷贝为路径名称」。多选路径仍逐行写入剪贴板。

升级包沿用本地 ad-hoc 签名。安装后如果已启用的访达剪切显示缺少权限，请为当前安装的 ClickMateHelper 重新确认已有的辅助功能授权。

## ClickMate 1.3.7 (build 16)

When copy path is enabled as a top-level Finder shortcut, the title follows Finder’s selection. For example, it shows `Copy “example.txt” as Pathname` for one item and `Copy 3 Items as Pathnames` for three items. The Copy submenu still offers “Copy as Pathname.” Multiple paths are still copied one per line.

The installer uses the fork’s existing ad-hoc signing. After updating, macOS might require the installed ClickMateHelper to be reauthorized for Finder Cut.
